Setup: upload renderer.typ to your R2 bucket

The Markdown renderer requires a /renderer.typ file in your bucket. Upload it via the file manager or with:

curl -X PUT "https://your-worker.workers.dev/api/upload?filename=/renderer.typ" \
  -H "x-api-key: YOUR_KEY" \
  -H "Content-Type: text/plain" \
  --data-binary @renderer.typ

Get renderer.typ from the repository.

Enter a file path above and click Render.
